# Becker 0.4.2-beta.1

Requires Home Assistant Core 2026.10.2 or newer (also declared in HACS).

- Replace the deprecated global device lookup with
  `async_get_device_by_identifier((DOMAIN, HUB_UNIQUE_ID), entry.entry_id)`
  and verify ownership with `config_entry_id`.
- Remove only the unused extra USB hub device originally registered by beta 3.
  Preserve records with active or disabled entities, child devices, via-device
  dependents (including other entries), user assignments or ambiguous identity;
  log why a record was kept. Do not register a replacement hub.
- Preserve existing cover devices and entity IDs, unique IDs and assignments.
  Keep the database, rolling codes, radio protocol and cover services unchanged.
- Add regression tests against the real Home Assistant device/entity registries,
  with serial setup mocked, including repeated setup and resource cleanup.

No live installation, integration reload, Home Assistant restart or physical
cover movement was performed as part of this maintenance change. Hardware
behavior and new live logs after installation remain to be checked separately.
