# Becker 0.4.1

This stable release brings the Becker Centronic USB integration's tested beta work together for Home Assistant 2026.8.

## Configuration and migration

- Set up the USB hub and covers through the Home Assistant integration flow.
- Edit hub paths and per-cover options through the integration's Configure menu.
- Import an existing Becker YAML setup into a passive UI entry, then activate it after removing the YAML platform and restarting Home Assistant.
- Select roller shutters or venetian blinds and configure position tracking, remote IDs, slat behavior and sun-protection positions.

## Cover control and position tracking

- Correct a cover's estimated position with `becker.set_known_position` without transmitting a radio command.
- Control the receiver's programmed DOWN intermediate position and configure native sun-protection behavior.
- Improve position estimates for short blind movements and Becker remote double-tap commands, including SWC545 blind controls.
- Keep physical remote commands from being interrupted by stale timed stops.

## USB recovery and diagnostics

- Recreate the serial connection after a cold host boot and show a persistent notification when a host reboot is detected.
- Emit `becker_remote_packet_received` events with decoded actions and raw command bytes.
- Serialize commands and sender-counter updates through the USB worker so only one process owns the counter database.

## Known limitations

- Becker receivers do not acknowledge movement to the USB stick. Home Assistant positions are estimates based on travel times, remote packets and optional templates; a completed Home Assistant action does not prove that a motor received the command.
- After a cold host reboot, the USB stick may need to be physically reconnected. If Home Assistant Core restarts again shortly afterward, the reboot notification may not remain visible. When the stick is unresponsive, reconnect it and verify one cover physically even if the notification is absent.
- Back up the sender-counter database and never run multiple controllers against the same stick and database.
