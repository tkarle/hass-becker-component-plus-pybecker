# Becker 0.4.2-beta.2

Fix cover controls becoming unavailable at estimated end positions. After sun
protection lowers a venetian blind to 0%, its slats may still need a normal
DOWN command to close fully. Compatible dashboards can now keep that command
available.

- Automatically publish `assumed_state: true` for all Becker covers: roller
  shutters and venetian blinds, with or without travel times and with position
  value templates. Centronic provides no receiver feedback; a template alone
  does not establish confirmed position feedback.
- Apply the change to existing UI and YAML covers without reconfiguration,
  an extra setup checkbox or manual YAML customization.
- Preserve estimated percentages, position sliders, sun protection, device
  identities, availability and existing radio command handling. No slat angle
  tracking is added.
- Add regressions for HA-published state attributes at 0% and 100% across
  supported position sources, and for normal close after DOWN2 sun protection.

Requires Home Assistant Core 2026.10.2 or newer. After installing the update
through HACS, restart Home Assistant to load the new integration code. Cards
must support `assumed_state` to keep both directional controls available.

Verification uses mocked hardware; no real cover movement is part of the test
suite. A real close from sun protection still needs a separately confirmed test.
